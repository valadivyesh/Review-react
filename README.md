💼 Customer Feedback & Issue Reporting System

The Customer Feedback & Issue Reporting System is a production-style React application designed to replicate how real companies collect, validate, and manage customer feedback and issue reports.
It focuses on handling complex forms, dynamic inputs, mixed component patterns, and instant state-driven UI updates — exactly the way modern SaaS support portals, CRM dashboards, and helpdesk systems work behind the scenes.

This system allows users to submit detailed bug reports, complaints, suggestions, and improvement ideas through a clean, responsive, and professionally designed form. The goal of the project is to give developers hands-on experience with real-world React concepts that are essential for building scalable, user-friendly front-end applications.

At the core of this project is a fully interactive form, built using both controlled and uncontrolled components. Critical fields such as name, email, category, priority, description, steps, and suggestions are implemented as controlled components to maintain strict validation and predictable React behavior. Optional fields like screenshot URLs and extra notes use Refs as uncontrolled components, representing how real applications balance performance and simplicity.

The system demonstrates advanced React event handling, including onChange, onBlur, onFocus, and onSubmit, allowing the UI to respond instantly to every user action. Dynamic lists allow users to add or remove “Steps to Reproduce” or “Suggested Improvements,” closely resembling workflows in platforms like JIRA, GitHub Issues, and Zendesk.

The application includes industry-standard form validation, such as email pattern checks, required fields, minimum length enforcement, and field-level error states. Inputs automatically highlight, errors appear in real-time, and the submit button only activates when the form becomes valid. This ensures a smooth and professional user experience.

Once feedback is submitted, it is displayed immediately inside a modern, card-based Feedback Dashboard. Each card shows the user’s details, category, priority badges, description, screenshot preview, steps, suggestions, and timestamp. This dashboard is built using conditional rendering, list mapping, and smart state management, providing a complete demonstration of how real user-generated content is handled in React applications.

Overall, this project teaches the practical implementation of:

Complex form handling

Real-time validation

Controlled + Uncontrolled components

Dynamic field management

Clean UI/UX practices

Component-based architecture

State lifting & data flow

By working through this system, developers gain the exact skills required to build real-world issue reporting tools, customer portals, and professional-grade React applications.
